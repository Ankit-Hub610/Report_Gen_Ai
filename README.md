🎯 Why I built this
Most small businesses, sports academies, coaching centers, and payment-link sellers sit on transaction/booking data with no analyst and no time to build a dashboard by hand. RA-I closes that gap end-to-end — upload a file, get KPIs, charts, and a full plain-language business report in minutes.

⚙️ What it does
📥 Auto-detects columns from any dataset — no fixed schema needed
📊 Generates KPI cards + 10 chart types automatically, each with a one-line insight
🧩 Power BI–style custom builder for your own cards/charts
⭐ Curated "Boss Dashboard" with full theming + one-click PDF export
📈 Deep-dive report: trend, forecast, anomalies, and an AI-written summary — where the business is winning, losing, and what to do next
🤖 Chat with your data in plain English/Hindi, grounded in real queries — never hallucinated numbers
🔐 Multi-tenant, role-based access (Admin / Client / Report Viewer) — one deployment safely serves many clients

🛠️ Tech stack
Python • Streamlit • Pandas/NumPy • Plotly • ReportLab • SQLAlchemy • LLM-powered narrative layer

👥 Who it's for
Sports academies & booking platforms • D2C/e-commerce sellers • Payment-link businesses • Agencies managing multiple clients • Founders without a BI team
